# Installation

Copy and paste this prompt into your agent:

```text
Install the cinematic-narrative-video skill from:
https://github.com/selther-core/animated-video-skill-mcp

First identify what this agent supports. Download or clone the repository into the
workspace if permitted, and read its SKILL.md and mcp/README.md. Preserve all of the
skill's supporting folders and do not overwrite any existing files or settings.

If this agent supports native skills, install the skill using this host's documented
skill location and verify that it can be discovered. If native skills are not
supported, make SKILL.md and its supporting files available as project instructions
instead, so the agent can follow them when I ask it to use the skill.

If this host supports local stdio MCP and configuration is permitted, register the
included MCP server using the instructions in mcp/README.md. Run the included tests
and verify the connection. MCP is optional: if it cannot be installed, the skill
should still be usable through its instructions. Do not change global settings or
install dependencies without any approval required by the host.

Report what was installed, how I can invoke it, and any step you could not verify.
Do not create a video or ask for a video topic yet.
```
